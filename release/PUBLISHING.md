# Как выложить «Стальной Фронт 3D» на игровые площадки

Регистрация, договоры и выплаты оформляются только на вас: войти в ваши аккаунты, принять условия площадок и указать платёжные данные можно только самостоятельно. Всё остальное подготовлено в этой папке.

## Что лежит в папке `release/`
| Файл | Для чего |
|---|---|
| `steel-front-3d-web.zip` | Сама игра: `index.html` в корне архива и папка `assets/` (~30 МБ). Загружается на площадки как HTML5-игра. |
| `screenshots/*.png` | 5 скриншотов 1280×720: ангар, деревня, лес, бой, снайперский прицел. |
| `cover_630x500.png` | Обложка для itch.io. |
| `cover_800x470.png` | Обложка для Яндекс Игр и каталогов. |
| `cover_1920x1080.png` | Большой баннер (CrazyGames, страницы игры). |
| `cover_512x384.png` | Обложка для GameDistribution и мелких каталогов. |
| `icon_512.png` | Иконка 512×512. |
| `DESCRIPTION.md` | Названия, короткое и полное описание (RU/EN), теги, рейтинг, лицензии ассетов. |

Требования площадок меняются: перед загрузкой сверьтесь с их актуальными правилами.

## 1. itch.io — самый простой старт, без SDK
1. Зарегистрируйтесь на itch.io и нажмите **Upload new project**.
2. Kind of project: **HTML**. Загрузите `steel-front-3d-web.zip` и отметьте **This file will be played in the browser**.
3. Размер окна: 1280×720, включите **Fullscreen button** и **Mobile friendly**.
4. Вставьте описание из `DESCRIPTION.md`, обложку `cover_630x500.png`, скриншоты, жанр и теги.
5. Монетизация: **Pricing → No payments / Donations / Paid**. Для бесплатной игры выберите приём пожертвований. Выплаты настраиваются в разделе Payouts (PayPal или Stripe).

## 2. Яндекс Игры — реклама, большая русскоязычная аудитория
1. Консоль разработчика: games.yandex.ru/console (вход через Яндекс ID).
2. Для выплат нужен статус самозанятого, ИП или юрлица — смотрите раздел «Монетизация» в консоли.
3. Обязательна интеграция Yandex Games SDK: показ рекламы между боями и за награду, а также сигнал «игра загружена». Без неё игру не пропустят на модерации — эту интеграцию могу сделать я.
4. Загрузите архив, обложку `cover_800x470.png`, иконку, скриншоты и описание.
5. Онлайн-режим соединяет игроков напрямую через внешний сервер PeerJS. Если модерация попросит убрать внешние подключения, в сборке для Яндекса онлайн можно отключить.

## 3. CrazyGames — международная аудитория, реклама
1. Портал разработчика: developer.crazygames.com.
2. Требуется CrazyGames SDK: реклама, события «игра началась» и «бой начался». Интеграцию могу сделать я.
3. Сначала игру тестируют на небольшом проценте игроков, потом расширяют показ. Важна скорость загрузки: первая загрузка игры ~30 МБ, это допустимо, но меньше — лучше.

## 4. GameDistribution — раздача игры на сотни сайтов
1. Регистрация: gamedistribution.com (Developer).
2. Требуется их SDK для рекламы. Доход — доля от показов рекламы на сайтах-партнёрах.
3. Обложка: `cover_512x384.png` и баннер 1280×720 из скриншотов.

## 5. Poki — по заявке
Poki отбирает игры вручную: отправьте ссылку https://makys0.github.io/Tg/ через форму для разработчиков на их сайте.

## Порядок, который я рекомендую
1. **itch.io** — сразу, без доработок.
2. **Яндекс Игры** — после интеграции Yandex SDK (реклама между боями и ролик за кредиты).
3. **CrazyGames / GameDistribution** — после интеграции их SDK.

Для каждой площадки нужна своя сборка с её SDK.

## Права
Все модели, текстуры и звуки — CC0 (Poly Haven, BigSoundBank, OpenGameArt), движок three.js и PeerJS — MIT. Игру можно распространять и монетизировать; блок с лицензиями есть в `DESCRIPTION.md`.
