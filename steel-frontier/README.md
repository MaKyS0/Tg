# Стальной Рубеж — 3D танковый экшен

Оригинальная 3D-игра о танковых сражениях в духе «гараж → бой → награда → прокачка».
Все названия, модели, карты, звуки и текстуры созданы процедурно в коде проекта — внешних ассетов нет.

## Стек и почему он

**TypeScript + Three.js (WebGL 2) + Vite + Vitest** — одна кодовая база для всех платформ:

* браузер на ПК (клавиатура/мышь/геймпад) и на телефонах/планшетах (touch) — без отдельных сборок;
* та же сборка `dist/` упаковывается в Electron/Tauri (desktop), Capacitor (Android/iOS) или публикуется как
  Telegram Mini App — различия платформ спрятаны в `InputManager`/`TouchControls`/`RendererCore`;
* симуляция боя не зависит от рендера и запускается в Node.js — это и автотесты, и задел под
  серверный (авторитетный) мультиплеер;
* Three.js даёт PBR-материалы, тени, инстансинг, IBL и работает даже на слабых устройствах
  (профили качества low…ultra).

## Запуск

```bash
cd steel-frontier
npm install          # зависимости
npm run dev          # дев-сервер: http://localhost:5173
npm run build        # проверка типов + продакшен-сборка в dist/
npm run preview      # запуск собранной версии: http://localhost:4173
npm test             # автотесты (данные, броня, баллистика, прокачка, сохранения, полный бой ботов)
npm run typecheck    # только проверка типов
```

Требуется Node.js 20+ и браузер с WebGL 2.

| Снайперский прицел / арт-прицел САУ | Shift, колесо до упора | LT | ПРИЦЕЛ, +/− |

## A. Архитектура

```
             ┌──────────────── data/ (контент, без логики) ────────────────┐
             │ nations · classes · techTree · tankFactory · ammo · surfaces │
             │ crew · gameModes · maps · registry (валидация, поиск)        │
             └───────────────┬───────────────────────────────┬─────────────┘
                             │                               │
        ┌────────── sim/ (детерминированная симуляция, 60 Гц, без DOM/WebGL) ──────────┐
        │ World ── шаг: controllers → TankCombat → TankPhysics → коллизии →            │
        │          ProjectileSystem(Ballistics) → ArmorSystem → DamageSystem →          │
        │          DetectionSystem → GameModeState → события EventBus                  │
        │ MapBuilder → Terrain + StaticWorld(spatial hash) → NavGrid(A*)               │
        │ ai/: AIController (утилитарный выбор состояний) + TeamBrain (радио, фокус)   │
        │ Battle: матчмейкинг, спавн, боты                                             │
        └───────────────┬─────────────────────────────────────┬───────────────────────┘
                        │ события / чтение состояния          │ TankInput
        ┌───── render/ ─┴─────┐  ┌──── audio/ ────┐  ┌──── input/ ─┴──────┐  ┌──── game/ ────┐
        │ BattleScene, Terrain│  │ AudioSystem    │  │ InputManager       │  │ Progression   │
        │ Props(инстансинг,LOD│  │ (WebAudio,     │  │ (клав/мышь/геймпад)│  │ Economy       │
        │ ), TankView/LOD,    │  │ процедурный)   │  │ TouchControls      │  │ SaveSystem    │
        │ Effects, Sky, Camera│  └────────────────┘  └────────────────────┘  └───────────────┘
        └─────────────────────┘                ui/: Garage, TechTree, HUD, Minimap, Results, Settings
                                         app/: App (машина состояний, игровой цикл), PlayerController
```

Ключевые принципы:

* **Data-driven.** Танк = строка в дереве (`techTree.ts`) + базовые параметры класса/уровня/нации.
  `tankFactory.ts` разворачивает её в полный `TankData` (корпус, башни, орудия со снарядами, двигатели,
  ходовые, радиостанции, экипаж, маскировка, цена, опыт). Добавить танк — добавить строку
  в `EXTRA_TANKS` или имя в линию нации. Новая нация — запись в `NATIONS`. Новая карта — объект `MapData`
  из декларативных фич (холмы, реки, города, леса…). Новый режим — запись `GameModeData`.
* **Одно представление брони** (`ArmorModel.ts`): выпуклые многогранники корпуса/башни/рубки, маска,
  командирская башенка, гусеницы, экраны, ствол и внутренние модули. Те же полигоны идут в рендер,
  поэтому попадание приходится ровно туда, куда видно.
* **Контроллеры** (`TankController`): игрок, ИИ и (в будущем) сетевой прокси пишут один и тот же
  `TankInput`. Симуляция идёт фиксированным шагом, рендер интерполирует между шагами.
* **События** (`EventBus<WorldEvents>`): симуляция ничего не знает о графике/звуке/UI.

## Что реализовано

* **6 наций** (СССР, Германия, США, Великобритания, Франция, Япония), у каждой 5 веток: основная I–X
  (ЛТ→СТ), лёгкие IV–VIII, тяжёлые V–X, ПТ-САУ IV–X, САУ IV–VII + премиум-машины — **195 танков**.
  Национальные особенности: наклон брони, точность, скорость снаряда, ВН/УГН, магазины у Франции,
  экраны у Германии, башенные ПТ у США/Британии и т. д.
* **Модули**: 2 орудия, 1–2 башни, 2 двигателя, 2 ходовые, 2 радиостанции на танк; исследование опытом,
  покупка, совместимость «орудие ↔ башня» и предел нагрузки ходовой.
* **Повреждения модулей в бою**: двигатель (мощность, пожар), трансмиссия, гусеницы (обездвиживание),
  орудие (разброс/сведение, блокировка), погон башни (скорость/заклинивание), радиостанция (связь и обзор),
  боеукладка (перезарядка, детонация с отрывом башни), топливный бак. Автоматический ремонт до «повреждён»,
  ремкомплект, аптечка, огнетушитель. Ранения экипажа влияют на соответствующие характеристики.
* **Снаряды** ББ/БП/ОФ/КС с массой, калибром, сопротивлением воздуха, падением пробития от скорости,
  нормализацией, рикошетом, перекрытием калибром; КС теряет пробитие за экранами; ОФ — сплэш и урон без пробития.
* **Баллистика** с гравитацией и сопротивлением, трассеры; САУ — отдельная модель (высокая гравитация,
  навесная траектория, решатель угла, верхний прицел).
* **Физика**: мощность/масса, тяговое ограничение по сцеплению, сопротивление грунта по типу ходовой,
  7 поверхностей + вода + лёд, склоны и сползание, занос, разные скорости гусениц, подвеска, падения,
  столкновения, таран, снос разрушаемых объектов, утопление.
* **8 карт** (степь, город, пустыня, зима, лес, промзона, горы, побережье) с рельефом, реками/озёрами/морем,
  дорогами, постройками, лесами, кустами, скалами, руинами, баррикадами; маршруты ТТ/ЛТ, позиции снайперов.
* **Разрушаемость**: деревянные/глинобитные дома (в руины), заборы, ящики, машины, вагоны, стены, баррикады,
  деревья (падают). Разрушение открывает проезд (навигация пересчитывается) и линию видимости.
* **ИИ** четырёх уровней сложности: роли по классам, A*-навигация с обходом и выходом из застреваний,
  выбор цели (угроза, пробиваемость, добивание, защита базы), выбор снаряда, упреждение, ожидание сведения,
  стрельба по слабым зонам, ромбование, укрытия на перезарядке, отступление, помощь союзникам по радио,
  захват и защита базы, реакция на радиокоманды игрока.
* **Режимы**: стандартный, захват, встречный, штурм; бои до 15×15.
* **Обнаружение**: обзор vs маскировка, LOS через рельеф и здания, кусты и листва на линии, размер,
  движение, стрельба, обмен разведданными по дальности связи, «лампа» засвета.
* **Гараж**: 3D-витрина, характеристики, модули, боекомплект, экипаж (обучение, навыки), статистика,
  дерево исследований, покупка/продажа, перевод опыта.
* **HUD**: HP, модули, экипаж, перезарядка, снаряды, сведение с индикатором пробития, маркеры над танками,
  списки команд, счёт, таймер, захват, направление корпуса/башни/камеры, скорость, лог попаданий,
  килл-фид, радио, мини-карта (союзники, засвеченные враги, базы, взгляд, сетка, объекты).
* **Графика**: PBR (albedo/normal/roughness/metalness/AO, IBL), тени, туман, небо с облаками, bloom (high/ultra), частицы
  (дым, пыль, огонь, вспышки, искры, обломки, брызги), трассеры, следы гусениц, декали попаданий,
  обгорание подбитых танков. Оптимизация: инстансинг, чанки растительности с LOD и дистанционным отсечением,
  LOD танков, пулы частиц/снарядов/декалей, фиксированное число источников света, асинхронная загрузка карты.
* **Звук**: двигатель с переключением передач, гусеницы, выстрелы с учётом дистанции (задержка и глушение),
  попадания, рикошеты, взрывы, модули, перезарядка, окружение по биому, радио (+ синтез речи).
* **Сохранения**: версионированный формат с контрольной суммой, резервная копия, миграции, экспорт/импорт.

## E. Проверка

Автотесты (`npm test`, 30+ тестов): валидность контента и дерева, геометрия брони и правила пробития
(угол, нормализация, перекрытие, рикошет, экраны против КС, фугасы), баллистика и решатель САУ,
прокачка/покупка/модули/экипаж, сохранения (повреждение, резервная копия, подмена данных, экспорт),
навигация на всех картах, обнаружение (LOS, кусты, выстрел), физика (масса, грунт, повреждения),
стрельба, захват базы и полный бой ботов. Дополнительно игра прогонялась в headless Chromium (WebGL)
на всех картах, в гараже, в бою, в снайперском и артиллерийском прицеле, на мобильном экране с touch.

Найдено и исправлено при внутренней проверке:

* матчмейкинг на I–III уровнях подбирал машины IV уровня (нет классов на низких уровнях) — теперь
  приоритет у уровня, класс подбирается в пределах ±1;
* точки появления попадали на склон бортика карты — бортик строится до выравнивания баз, ряды спавна центрированы;
* тяжёлые танки не могли заехать на склоны ~20° (слишком низкая тяга на малой скорости) — исправлена модель
  тяги, согласованы пороги уклона навигации, добавлены обходные точки при застревании;
* ИИ-САУ стреляли по целям вне досягаемости — фильтр по баллистической дальности;
* потеря пробития КС за экранами накапливалась мультипликативно от первой брони — считается по воздушному зазору;
* при недоступном захвате курсора первый клик никогда не стрелял — учтены ошибки pointer lock;
* гусеница-«коробка» скрывала катки — гусеничная лента теперь открытый контур;
* выведение типа-предиката TS сужало массив боекомплекта до `0[]` — исправлено условие;
* лишние аллокации в ИИ (память целей) и в HUD (трассировка траектории) — убраны;
* touch-кнопки перекрывали мини-карту/слоты — слоты снарядов и расходников стали кнопками, мини-карта сверху.

Известные ограничения: сетевой мультиплеер не реализован (архитектура готова, см. ниже); модели танков —
процедурные low-poly; SSAO не используется (AO из текстур и вершинное затенение рельефа).

## Задел под мультиплеер

`World` — авторитетная симуляция с фиксированным шагом, весь ввод идёт через `TankInput`, а визуализация —
через события и чтение состояния. Для сетевой игры добавляется `NetworkController` (вход от клиента на сервере)
и рассылка снимков состояния танков/снарядов клиентам; `sim/` уже собирается и работает в Node.js (см. тесты).
