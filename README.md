# Coin Clicker — Telegram Mini App

Простое мини‑приложение для Telegram: нажимаешь на монетку — счёт растёт на 1.

- `webapp/index.html` — само мини‑приложение (один HTML‑файл, без сборки).
  Весь прогресс (счёт, улучшения, скины, миры, награды) сохраняется в Telegram CloudStorage (привязан к пользователю,
  виден на всех устройствах); вне Telegram — в `localStorage`. Есть вибрация при клике и анимация «+N».
  Оформление: шрифты Unbounded и Onest (Google Fonts, с запасными системными), поверхности строятся от цветов темы Telegram,
  поэтому светлая и тёмная темы работают одинаково; вокруг монеты светящийся ореол цвета скина.
  - **Улучшения:** «Сила клика» (+1 за клик), «Автокликер» (+1 монета в секунду), «Множитель» (+25% ко всему доходу).
    Цена каждого уровня растёт.
  - **Магазин скинов:** 17 скинов в пяти редкостях, бонус к клику действует, пока скин надет.
    Обычные: Классика, Серебро (+1), Бронза (+2). Редкие: Изумруд (+3), Жемчуг (+5), Рубин (+10).
    Эпические: Сапфир (+18), Алмаз (+30), Кварц (+50). Легендарные: Аметист (+100), Платина (+200),
    Магма (+400), Неон (+700). Мифические: Галактика (+1500), Обсидиан (+3000), Призма (+8000, переливается),
    Корона (+20000).
  - **Миры:** Луг (×1), Пустыня (×2), Ледник (×4), Вулкан (×8), Океан (×16), Космос (×32) — множитель
    ко всему доходу, пока ты в этом мире. Открываются по порядку за монеты и требуют перерождений
    (1, 3, 6, 10, 15). Открытые миры остаются навсегда, между ними можно свободно перемещаться.
    У каждого мира свой фон, пейзаж и частицы (светлячки, песок, снег, искры, пузыри, звёзды).
  - **Награды:** ежедневный подарок (серия дней, на 7-й день бонус кристаллами) и 17 достижений за кристаллы
    (клики, заработанные монеты, перерождения, скины, миры, золотые монеты). Прогресс достижений не сбрасывается перерождением.
  - **Золотая монета:** время от времени пролетает по экрану; поймаешь — получишь куш монет или «золотую лихорадку»
    (клики ×7 на 15 секунд). Каждый клик с шансом 8% становится критическим (×5).
  - **Офлайн-доход:** пока тебя нет (до 3 часов), автокликеры приносят 50% дохода.
  - **Десктоп:** на широком экране игра раскладывается на две колонки (монета слева, магазин справа),
    есть подсветка при наведении, видимый фокус для клавиатуры, клавиши 1–5 переключают вкладки.
  - **Перерождение:** сбрасывает монеты и улучшения (скины и миры остаются) и даёт кристаллы:
    `floor(sqrt(заработано_за_забег / 2000))`. Кристаллы тратятся на постоянные улучшения:
    «Золотая жила» (+50% к доходу), «Стартовый капитал» (+200 стартовых монет), «Торговец» (−5% к цене улучшений, до −50%),
    «Кристальный дар» (+25% кристаллов).
  - **Управление:** тап/клик по монете или клавиша Пробел.
- `bot.py` — бот на aiogram 3: по `/start` присылает кнопку «Играть» и ставит кнопку меню, открывающую игру.

## Запуск

1. **Создай бота** у [@BotFather](https://t.me/BotFather) командой `/newbot` и скопируй токен.
2. **Опубликуй `webapp/` по HTTPS** (Telegram требует HTTPS). Проще всего — GitHub Pages:
   Settings → Pages → Source: `Deploy from a branch`, ветка `main`, папка `/ (root)`.
   Приложение будет доступно по адресу `https://<user>.github.io/<repo>/webapp/`.
3. **Настрой и запусти бота:**
   ```bash
   cp .env.example .env        # впиши BOT_TOKEN и WEBAPP_URL
   python -m venv .venv && source .venv/bin/activate
   pip install -r requirements.txt
   python bot.py
   ```
4. Открой бота в Telegram, отправь `/start` и нажми «🪙 Играть».

Игра уже опубликована: https://makys0.github.io/Tg/webapp/ (ветка `gh-pages`, папка `webapp/`; этот адрес можно вписать в `WEBAPP_URL`).

Локально страницу можно проверить просто открыв `webapp/index.html` в браузере.
